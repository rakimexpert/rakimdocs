# RAKIM Expert - API Documentation 🚀

Bem-vindo à documentação oficial das APIs do **RAKIM Expert**. Este repositório foi criado para fornecer clareza e facilidade de integração para nossos clientes e parceiros.

## 🛠️ Como Utilizar esta Documentação

Utilizamos o **Bruno**, um cliente de API open-source que permite versionar documentação de forma limpa e eficiente.

1.  **Baixe o Bruno:** [usebruno.com](https://www.usebruno.com/)
2.  **Abra a Collection:** No Bruno, clique em "Open Collection" e selecione a pasta `docs/api/bruno-collection` deste repositório.
3.  **Explore:** Todos os endpoints, exemplos de request/response e documentações estão organizados em arquivos `.bru`.

## 📂 Estrutura do Repositório

- `docs/api/bruno-collection/`: Arquivos de definição da API.
- `README.md`: Este guia de início rápido.
